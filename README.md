Description:
------------------------------------------
This program takes a provided input file of two matrices 
and performs various matrix operations on them
such as addition, dot product, transpose, and trace.
It outputs all results onto a provided output file

Sources:
------------------------------------------
All code is written by myself.

This program was built to familiarize myself with
matrices and their operations. Much time went into 
inventing elegant solutions to complex operations
such as finding the submatrix. In the future, this
program may be improved upon by expanding the limit
from a simple 3x3 matrix to matrices of any size
